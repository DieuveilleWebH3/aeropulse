S0-004 POST-APPLY VALIDATION

This patch intentionally does NOT hand-edit uv.lock.

After applying the patch with uv >=0.13.6 and Python 3.14.10:

  uv lock
  uv sync --locked
  uv run --locked ruff check .
  uv run --locked ruff format --check .
  uv run --locked mypy
  uv run --locked pytest
  uv run --locked pre-commit run --all-files
  uv run --locked pre-commit run --all-files --hook-stage pre-push

Then review and commit the resolver-generated uv.lock together with S0-004.

Do not commit S0-004 with a stale uv.lock.
